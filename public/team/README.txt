Team photographs.

Drop the founder portrait in this folder. Any filename, any common image
format (jpg, png, webp, avif) — FounderCard scans this directory and uses
the first image it finds, preferring a name containing "moses", "founder"
or "portrait".

Square images read best (800x800 or larger). The frame crops with
object-fit: cover, so anything roughly square works.

With no image here, the card shows "MS" initials instead.
